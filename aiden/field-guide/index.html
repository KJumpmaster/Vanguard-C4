Install the Field Guide

In a supported browser, use the install icon in the address bar. If no install prompt appears, the viewer still works in a browser tab.

For a Windows desktop copy, download the package, extract it, and run Install_Field_Guide.vbs. It adds a desktop shortcut and opens the guide in your default browser. No PowerShell is required, and no DOS window appears.
